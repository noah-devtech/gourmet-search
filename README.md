# 【非公式】獅子まんまリスト

本システムはベルーナドーム内における飲食店の情報を共有するための非公式サイトです。
獅子まんまの価格や販売状況など、球団公式からの情報をもとに有志が独自に集計・更新しています。
これらの情報に対し絞り込みや検索を行うことで、目的の店舗やメニューを見つけやすくすることを目的としています。

## API仕様

### `/api/master-data`

- **メソッド**: GET
- **説明**: マスターデータをJSON形式で返すAPIエンドポイント
- **レスポンス例**:

    ```json
    {
        "data": [
            {
                "id": "P00202",
                "location": {
                    "base": 3,
                    "code": 6
                },
                "storeName": "からきち屋",
                "category": "food",
                "lastUpdated": "2026-03-21",
                "isActive": true,
                "tags": ["唐揚げ", "弁当", "大盛り"],
                "productName": "唐揚げ弁当",
                "price": 1300,
                "size": "大盛り",
                "options": "唐揚げ4個・ライス350g"
            }
        ]
    }
    ```

## 情報源に関する宣言

本シートに記載されている情報は、すべて「西武ライオンズ公式からのプレスリリース・公式サイト」および「店舗における一般向けの店頭掲示」など、すでに公開されている情報のみを元に独自に集計したものです。球団や店舗の非公開情報（内部資料）は一切使用・掲載しておりません。

## 免責事項

本シートは有志による個人製作であり、株式会社西武ライオンズ公式の情報ではありません。
情報の正確性には細心の注意を払っていますが、価格改定やメニュー変更、短期間のイベント等により、現場の状況と異なる場合があります。
最終的には必ず店舗の掲示や公式情報を優先し、案内時には「念のため店舗でご確認ください」等の添え言葉を推奨します。
本シートの情報を用いたことによるトラブルの責任は負いかねますので、各自の判断で活用してください。
