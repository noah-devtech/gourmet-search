## Overview
本システムはベルーナドーム内における飲食店の情報を共有するための非公式サイトです。
獅子まんまの価格や販売状況など、球団公式情報をもとに有志が独自に集計、更新しています。絞り込みや検索機能を通じて、目的の店舗やメニューへの迅速なアクセスを可能にします。

## 開発の理念と目的
ベルーナドームの飲食エリアはその圧倒的なラインナップが魅力である一方、情報の多さゆえに「目的の品がどこにあるか分からない」という情報の断片化と知識の属人化が課題となっていました。
本システムは、現場での案内をよりスムーズにするため、以下の理念に基づき開発されています。

1. **情報の即時参照性**: スマートフォンから数秒でメニューや場所を特定可能にする。
2. **知識の標準化**: 全員が共通の正確なデータに基づいて案内を行える環境の提供。
3. **多角的なフィルタリング**: 「エリア」「店舗」「タグ」による柔軟な絞り込みの実現。

## 主な機能
- **多機能検索バー**: 商品名、店舗名、タグ（「唐揚げ」「大盛り」等）で即座に表示します。
- **塁側フィルタ**: 1塁・3塁のエリア別に絞り込み、現在地からの最適な案内を実現します。
- **ステータス管理**: 「今年確認済み」の鮮度管理や「販売終了」を含めた履歴確認が可能です。

## 使い方

### 1. キーワードによる迅速な検索
検索バーはAND検索に対応しており、リアルタイムに候補を絞り込みます。
- **検索対象**: 商品名、店舗名、特徴タグ、トッピング情報
- **入力例**: `弁当` `ビール` `ポテト`
> **活用例**: お客様から「唐揚げが食べたい」と問われた際、`唐揚げ` と入力するだけでドーム内の全候補をリストアップできます。

### 2. 現在地に基づくエリア絞り込み
ドーム内は広大なため、移動負担を減らすためのエリアフィルタを搭載しています。
- **操作**: 「1塁側」「3塁側」ボタンで、現在地付近の店舗のみを抽出します。
> **現場での活用シーン**:
> 「一番近いカレー屋さんは？」という問いに対し、エリアを絞った上で検索することで、お客様を迷わせることなく最短の店舗へ案内可能です。

### 3. データの鮮度・販売状況のコントロール
メニューの入れ替わりに対応し、表示する情報の時間軸を操作できます。
- **今年確認済みのみ**: 今シーズンに販売が確認されたデータのみ表示します（デフォルト：ON）。
- **販売終了を含める**: 過去のメニューを表示し、事実確認に活用できます（デフォルト：OFF）。

### 4. 検索結果（情報カード）の読み方
- **価格と商品名**: 商品名（太字）と価格（赤字）を最優先で表示します。
- **場所コード**: `📍 3塁側 / 場所コード: 6` の形式でドーム内の番地を示しています。
- **最終更新日**: データが最後に検証・確認された日付。古い場合は現場の状況が変わっている可能性があるため、現場状況を確認することを推奨します。
- **タグ**: 「大盛り」「限定」などの付加情報を視覚的に把握可能です。
